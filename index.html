🦊 Mozilla Firefox

Пошаговая инструкция установки для Firefox

product_extension.zip Архив .zip (без блокировок) / пакет .xpi
⬇ Скачать для Firefox (.zip) Скачать .xpi
💡 Совет: Рекомендуем скачивать .zip — Firefox загружает архивы сразу без блокировок. Если нужен .xpi: нажмите по кнопке правой кнопкой мыши ➔ «Сохранить ссылку как...».
  1. 1
    Скачайте дополнение (.zip или .xpi)

    Нажмите синюю кнопку «Скачать для Firefox (.zip)» выше. Файл сразу сохранится в папку «Загрузки» без блокировок безопасности.

  2. 2
    Откройте меню временных дополнений Firefox
    about:debugging#/runtime/this-firefox
    (Вставьте этот адрес в адресную строку Firefox и нажмите Enter)
  3. 3
    Загрузите временное дополнение

    В блоке «Этот Firefox» нажмите кнопку «Загрузить временное дополнение...» и выберите ваш скачанный .zip (или .xpi) файл.

  4. 4
    Готово к запуску!

    Дополнение активируется и появится в панели дополнений Firefox. Продукт готов к использованию.

🌐 Chromium

Пошаговая инструкция установки для Chrome / Edge / Яндекс

product_extension.zip Архив .zip с файлами
⬇ Скачать для Chromium (.zip)
  1. 1
    Скачайте и распакуйте архив

    Нажмите синюю кнопку «Скачать для Chromium (.zip)» выше и распакуйте архив в отдельную папку.

  2. 2
    Откройте страницу расширений в браузере
    chrome://extensions/
    (Для Яндекс.Браузера: browser://tune/, для Edge: edge://extensions/)
  3. 3
    Включите «Режим разработчика»

    В правом верхнем углу страницы расширений включите тумблер «Режим разработчика» (Developer mode).

  4. 4
    Загрузите распакованное расширение

    В левом верхнем углу нажмите кнопку «Загрузить распакованное расширение» (Load unpacked) и выберите вашу распакованную папку.

  5. 5
    Установка завершена!

    Закрепите расширение значком булавки 📌 в панели браузера и открывайте продукт.
